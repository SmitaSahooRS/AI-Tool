About this project

TestGen AI is a portfolio project demonstrating AI integration for QA engineers. It uses the Claude API to generate structured test cases from natural language feature descriptions.

Key techniques used:

  • Prompt engineering with strict JSON schema enforcement
  • Multi-format output (Gherkin, step-by-step, structured)
  • Client-side state management and localStorage persistence
  • CSV export and clipboard integration
  • API key management with browser-local storage

Built with vanilla HTML/CSS/JS + Anthropic API. No frameworks, no backend.
